# Simmerly — Project Plan & Requirements Traceability (Allrecipes-style MVP)

> Working brand name: **Simmerly** (name in `src/lib/site.ts`, wordmark in `src/components/layout/Logo.tsx`).
> Reference site: https://www.allrecipes.com/. We reproduce its **layout, information architecture, page
> templates, type scale, color system and interactions**. Per §8 of the brief we do **not** copy Allrecipes'
> logo, trademarks, recipe text, photos or videos: all demo text is original, demo photos are hot-linked from
> Unsplash (free licence), and demo videos are original step-by-step clips generated by
> `scripts/make-demo-videos.ts`. Client-approved content replaces them before launch.

## 2. Reference-site audit (template inventory)

Automated fetching of allrecipes.com is blocked from our build environment, so templates follow the
reference site's known structure, and **side-by-side comparison against client-supplied screenshots is
part of Milestone 5**.

- **Header**: wordmark, pill search "Find a recipe or ingredient", Saved / Log In, uppercase nav row
  (Dinners · Meals · Ingredients · Occasions · Cuisines · Kitchen Tips · News · Features · About Us) with
  full-width dropdowns; compact sticky header after scrolling; mobile hamburger drawer with accordions.
- **Cards**: 4:3 image, uppercase orange category tag, bold title, orange stars + rating count, heart save.
- **Homepage**: hero + 3 stacked stories, "The Latest", category tiles, collection feature, articles,
  top-rated row, video row, newsletter.
- **Recipe page**: breadcrumb, H1, rating line, dek, byline, Save/Rate/Print/Share, hero, details card,
  ingredients + scaler, numbered directions, Cook's Note, Nutrition Facts, "Photos of …", reviews with
  histogram and sorting, "You'll Also Love".
- **Footer**: wordmark, social, newsletter, link columns, legal line.

Design tokens (`tailwind.config.ts`): brand `#ce4620` (hover `#a83a1a`), ink `#111111`, body `#262626`,
muted `#595959`, rule `#e6e6e6`, tint `#f5f5f5`. Type: Source Sans 3 (400–900).

## 3. Technology & architecture

| Layer | Choice |
|---|---|
| Frontend + SSR | Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS 3 |
| Backend | Server components + server actions; route handlers for `/api/save`, `/api/health`, `/api/v1/*` |
| Database | PostgreSQL 16 via Drizzle ORM (`src/db/schema.ts`, `npm run db:push`) |
| Search | Postgres weighted `tsvector` (title > ingredients > description) + trigram index |
| Auth | bcrypt; HS256 JWT in httpOnly cookie; roles user/contributor/editor/admin; session revocation |
| Media | `lib/storage.ts`: local disk (VPS, Docker volume) or Vercel Blob; magic-byte validation |
| Email | `lib/email.ts`: SMTP (e.g. Hostinger mailbox) + outbox log in admin |
| Deploy | Docker Compose: PostgreSQL + app + Caddy (automatic HTTPS); or Vercel + Neon |
| Backup | `deploy/backup.sh` / `deploy/restore.sh` (database + uploads, 14-day rotation) |
| Monitoring | `/api/health/` + Docker healthcheck |

Expansion seams: public API v1, storage/email adapters, search function, JSON homepage sections,
role system, settings table, redirects table, bulk importer.

`homepage_sections` · `pages` · `media` · `site_settings` · `redirects` · `contact_messages` ·
`email_outbox` · `newsletter_subscribers`.

## 5. URL structure (SEO)

`/recipe/{id}/{slug}/` · `/recipes/{id}/{slug}/` · `/collections/{slug}/` · `/article/{slug}/` ·
`/video/{id}/{slug}/` · `/cook/{username}/` · `/{page}/`. ID-based URLs redirect to the current slug;
slug-only URLs get automatic 308 redirects when renamed. Every template sets title, description,
canonical and OpenGraph; JSON-LD for Recipe, BreadcrumbList, Article and VideoObject; `sitemap.xml`,
`robots.txt`.

newsletter ESP integration, dedicated search engine (Meilisearch/Typesense), image CDN resizing,
ads, magazine subscriptions, "I made it" check-ins, following cooks, notifications, multi-language,
native mobile app (can use `/api/v1`).
